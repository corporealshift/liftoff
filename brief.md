# Liftoff

An android app that uses an LLM to generate daily workouts based on the objectives + constraints defined by the user and the user's previously completed workouts. It also works as a "checklist" of workouts completed so the user can check off things they've completed while they're at the gym.

## Problem

I have a hard time coming up with well rounded weight lifting exercises to do at the Gym. I want to keep track of the workouts I have completed too. I want workouts to be defined based on what structure I define (2-3 lifting days / week, 2-3 running days, run -> lift -> run -> lift -> run kind of structure) and what equipment/types of exercises are available (the gym isn't super huge).
