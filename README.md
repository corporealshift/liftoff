# Liftoff

A personal Android app that plans training weeks and runs workouts at the gym as a checklist,
using a local LLM (via nabu) to produce balanced weekly outlines and detailed session plans.
Built for one person on one phone, with all training data stored locally in Room. Plans are
generated by a coach agent running on the owner's PC; completed workouts feed back into the
next plan so load progresses based on actuals.

## How to build

Run the project gate (also what CI runs):

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

On this machine, use the pinned toolchain wrapper:

```bash
bash gradlew.sh :app:assembleDebug :app:testDebugUnitTest
```

## How to install

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```
